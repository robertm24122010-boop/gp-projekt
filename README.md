 🚀 Expedition Simulator (NASA-style 2D World)

 📌 Opis projektu

Jest to symulator wyprawy w dwuwymiarowym świecie napisany w Pythonie 3.11.

Gracz (lub pojazd/robot) porusza się po mapie 2D, zużywa energię, napotyka losowe zdarzenia i próbuje dotrzeć do celu.

Program działa w terminalu i wykonuje prostą symulację bez graficznego okna.

---

 🧠 Funkcje projektu

- ruch w 2D (x, y)
- kierunek oparty na kącie (0–359°)
- system energii (zasób)
- losowe zdarzenia:
  - burze
  - znaleziska
- elementy świata:
  - pułapki
  - bonusy
  - przeszkody
- granice świata (-100 do 100)
- prosta symulacja w terminalu
- raport końcowy misji
- możliwość ponownego uruchomienia symulacji
